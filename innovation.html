Agentic Robot Training Pipeline

Sim-to-Real with NVIDIA Isaac Sim & Isaac Lab · 2026

An autonomous mobile robot learns to navigate a large, furnished facility entirely in simulation — modelled in OpenUSD with measured physics — then trains via PPO across 1,024 parallel environments in NVIDIA Isaac Lab before shipping to a real ROS 2 stack with SLAM and Nav2 for live, point-to-point delivery missions. The whole pipeline was built with an agentic harness — Claude Code driving a remote GPU through 55 skills and 776 passing tests — improving training goal-reach from 40% to 92% across four diagnosed runs before validating full sim-to-deploy parity.

Personal Project · Open Source

Local AI Companion / "Duet" Chat Stack

SillyTavern + local & cloud LLMs · 2026 · Solo build, running entirely on a personal laptop

An open-source companion/"duet" chat stack: SillyTavern as the chat UI, swappable LLM backends (fully local via Ollama, or a hosted API like OpenRouter / NVIDIA NIM), full voice in/out, and live web search — all running on one laptop. "Duet" Group Chats put two AI personas in a single conversation, replying to each other as well as to the user. The whole stack runs fully offline on local models, or swaps to frontier cloud models with one config change.

Debugged along the way: a silent TTS failure traced to the server returning real WAV bytes mislabeled as MP3 — Chrome decodes that with no error and no sound — fixed by encoding genuine MP3 via ffmpeg; and a settings-sync bug between two internal flags, enabled and ttsEnabled, that let the UI show "on" while playback stayed silently disabled.
